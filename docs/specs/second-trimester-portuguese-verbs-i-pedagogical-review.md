# Revisao Pedagogica: Verbos I

## Parecer tecnico

Os 20 itens usam frases curtas para identificar acoes, completar contextos,
diferenciar agora de ontem e relacionar quem pratica a acao com formas verbais
frequentes. Cada item tem uma resposta unica e retorno respeitoso para os
distratores. Nao ha nomes de tempos verbais ou classificacoes avancadas.
