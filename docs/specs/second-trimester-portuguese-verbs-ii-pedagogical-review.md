# Revisao Pedagogica: Verbos II

## Parecer tecnico

Os 20 itens usam verbos distintos dos de Verbos I, com frases curtas,
marcadores temporais claros e concordancia frequente. As respostas sao unicas,
e os retornos explicam os erros sem linguagem punitiva. O pacote nao introduz
tempos verbais avancados nem nomenclatura tecnica.
